ALGEBRENGINE
-----------------------

Algebrengine is a currently Work-In-Progress Symbolic(?) Computer Algebra System Library for C#. 

It is intended to have a heavy focus on modding and customization, while still having a strict type adherence,
convenient architecture/writing, and solver presence.

The primary considerations for Algebrengine are more interactive apps than classical CAS's, such as in math
curricula or hobby problem-solving.

This README is also in progress, with the ideal next step to be an outline of the architecture (when it's completed)
